## 첫 학습용 구성

연속 장면의 반복을 줄이기 위해 숫자 프레임 순서의 0, 10, 20…번째와 마지막 프레임을 선택했습니다. 학습·검증을 외부 촬영 장면 단위로 분리합니다.

| 용도 | 외부 실내 자료 | 기존 식당 자료 | 합계 | 머리 박스 |
| --- | --- | --- | ---: | ---: |
| train | 카페 67장 | 16장 | 83장 | 1,882개 |
| val | 공연장 77장 | 4장 | 81장 | 1,882개 |

출력은 로컬 `data/head_aihub71368_v1/`입니다. `data.yaml`, 이미지·YOLO 라벨, 원본 연결·해시·분리 근거를 담은 `manifest.json`, `audit/validation.json`을 저장합니다. 클래스는 `0=head`이고 나이·성별·자세 등의 속성을 학습 대상으로 사용하지 않습니다.

검사 결과: 선택한 164장 전체 픽셀 디코딩 성공, 이미지 원본 바이트 보존, 동일 이미지 중복 없음, 좌표 역변환 최대 오차 약 0.000000096픽셀. Ultralytics 로더에서 164장·3,764개 박스를 누락·손상 없이 읽었고 1280 입력 배치를 생성했습니다.

외부 장면은 2개뿐이고 식당 검증 사진은 4장뿐입니다. 독립 테스트셋은 아직 없으며, 외부 검증 성능과 식당 성능을 분리해서 보고해야 합니다. 카페·공연장에 같은 출연자가 있을 수 있으므로 인물까지 독립된 분리라고 주장하지 않습니다. 실제 식당 혼잡도·좌석 점유 정확도는 이 데이터 준비 검사로 입증되지 않습니다.

## 재현

저장소 최상위에서 실행합니다. 이미 준비된 출력은 재사용하고 다시 만들 때는 새 폴더명을 지정합니다.

```bash
source .venv/bin/activate
python ai/prepare_aihub_head_dataset.py \
  --source "$HOME/Downloads/Sample 2" \
  --cafeteria-data data/head_cafeteria_v1 \
  --stride 10 \
  --output data/head_aihub71368_v1
```

이 변환기는 현재 받은 3개 시나리오를 명시적으로 검증합니다. 다른 촬영 그룹을 추가하려면 장면별 분리 설정과 라벨 구조를 먼저 확인해야 합니다. `--stride 1`은 두 실내 장면의 모든 프레임을 선택하지만 새로운 촬영 다양성을 만들어 주지는 않습니다.

첫 실행 점검용 학습 명령:

```bash
python ai/train_head_smoke.py \
  --data data/head_aihub71368_v1/data.yaml \
  --epochs 3 --device mps --name indoor_20261105_01
```

3 epoch는 실행 점검용이며 충분한 성능을 보장하는 학습 횟수가 아닙니다. 실행별 측정 결과는 `runs/head/<실행명>/summary.json`과 예측 사진으로 확인합니다.
