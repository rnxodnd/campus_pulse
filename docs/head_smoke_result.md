# 머리 탐지 첫 시험 학습 결과

2026-11-05, Mac M4에서 **학습 실행과 가중치 저장은 성공했으나 머리 탐지 성능은 확보하지 못했습니다.** 이 결과의 `best.pt`는 실행 점검 산출물이며 서비스에 사용할 모델이 아닙니다.

## 실제 실행 조건

| 항목 | 실행값 |
| --- | --- |
| 모델 | 공식 YOLOv8n 사전학습 가중치를 `head` 1개 클래스로 미세조정 |
| 학습 데이터 | 자체 촬영 16장, 머리 박스 64개 |
| 검증 데이터 | 이전 촬영 묶음 4장, 머리 박스 15개 |
| 독립 테스트 데이터 | 미확보 |
| 장치 | Apple M4, PyTorch MPS GPU |
| 라이브러리 | Python 3.12.16, torch 2.9.1, Ultralytics 8.3.253 |
| 입력·배치·횟수 | 1280, batch 2, 3 epoch |
| 옵티마이저 | AdamW, lr0=0.001, lrf=0.1, nbs=2, warmup_epochs=0 |
| 주요 증강 | mosaic=0, scale=0.1, translate=0.05; 기본 수평 뒤집기·색상 증강 유지 |
| 로딩·정밀도 | workers=0, cache=False, amp=False |
| 초기화·학습·최종 검증 시간 | 약 121.9초; 별도 사진 추론 시간 제외 |
| 로그상 학습 GPU 메모리 | 약 2.2~2.3GB; 시스템 전체 메모리 사용량과 다름 |

짧은 실행에서도 가중치 갱신을 확인하려고 warmup과 누적 배치를 명시했습니다. 본 학습용으로 최적화한 설정은 아닙니다. 초기 가중치 출처는 [Ultralytics 공식 자산](https://github.com/ultralytics/assets/releases/download/v8.3.0/yolov8n.pt)이며 COCO 이미지 데이터셋은 받지 않았습니다.

## 완료한 확인

- MPS 환경 점검과 실제 학습 로그의 `MPS (Apple M4)` 확인.
- 데이터 20장 모두 정상 로딩, `head` 단일 클래스 적용.
- 3 epoch 완료, 결과 CSV의 손실·지표·학습률에 NaN/Inf 없음.
- `best.pt`·`last.pt` 생성과 `best.pt` 재로딩 성공.
- 최종 검증 및 검증 사진 4장의 예측 이미지·좌표 저장.
- 학습 배치 이미지의 정답 박스와 머리 위치를 시각적으로 확인.

첫 epoch 검증에 `NMS time limit 2.200s exceeded` 경고가 한 번 발생했습니다. 따라서 첫 epoch 지표는 완전한 처리 결과로 신뢰하지 않습니다. 이후 epoch와 학습 종료 후 `best.pt` 최종 검증에는 같은 경고가 없었으며, 아래 지표는 마지막 별도 검증 결과입니다.

## 탐지 결과와 해석

최종 검증의 **Precision, Recall, mAP50, mAP50-95는 모두 0**입니다. 예측 이미지에서 천장 조명과 바닥을 머리로 잘못 탐지했으며, 머리 위치를 제대로 잡지 못했습니다. 학습 손실 감소만으로 모델이 목표 작업을 학습했다고 판단할 수 없습니다.

아래는 `best.pt`로 각 검증 사진을 별도 추론한 결과입니다. confidence=0.25, imgsz=1280을 사용했습니다. 숫자는 맞게 탐지한 머리 수가 아니라 모델이 출력한 박스 수입니다.

| 이미지 | 정답 머리 수 | 예측 박스 수 |
| --- | ---: | ---: |
| val_001.jpg | 2 | 5 |
| val_002.jpg | 3 | 5 |
| val_003.jpg | 5 | 3 |
| val_004.jpg | 5 | 0 |

인원수 차이의 평균 절댓값은 3.0명이지만, 배경 오탐과 머리 누락이 함께 발생하므로 이 값만으로 위치 정확도를 판단해서는 안 됩니다. 배치 검증과 단일 사진 추론은 패딩 형태가 달라 예측 박스 수가 달라질 수 있습니다.

현재 사진은 소수 인원의 비슷한 장면들입니다. 긴 변 1280으로 축소해도 학습 박스 64개 중 12개, 검증 박스 15개 중 6개는 한 변이 8픽셀 미만입니다. 이는 좌표로 계산한 크기이며 특정 오탐의 원인을 확정한 결과는 아닙니다. 입력 구역 분할, 데이터 다양성, 추가 학습을 다음 실험에서 검토해야 합니다.
